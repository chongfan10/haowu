# 苏州攻略  
## 山塘街（推荐晚上去）  
- [ ] 有阿娟馄饨店。店内有饺子（苏州叫馄饨）还有汤圆（苏州特色肉汤圆）。  
- [ ] 欣政尚甜品店。店内有苏州特色的甜品，如糖粥，苏式绿豆汤，是一家很老很正宗的店。  
- [ ] 江南蟹壳皇。地铁二号线山塘街站3号口出来就是，在菜市场。是酥酥脆脆的口感，，附近的几家店也很不错，比如旁边的烧麦  
- [ ] 阿月煲。苏州酥蹄煲里比较出名的，也是一家老店，但是我感觉他家酥蹄还是有点偏甜的，其他的还好，我舍友都很喜欢。  
- [ ] 东北一绝。东北菜，吃过很多次了，服务好，口味也不错，但是需要排队  
- [ ] 荣阳楼。油氽团子好吃，是油炸的，外皮酥糯，内心是肉丸。  
## 观前街（离平江路很近，步行可达）  
是一条商业街，有很多是骗外地人的，走走逛逛就行。  
- [ ] 蛮好阁。苏州本土包子，素馅也很好吃，会带有一点微甜，外皮有胡萝卜和黄瓜做的，很不错。  
- [ ] 魏家凉皮。汉堡很好吃，性价比很高，缺点是要排队。  
- [ ] 采芝斋。粽子糖、津津豆腐干、酒酿饼都很不错，苏州老店了。  
- [ ] 蜜雪冰城旗舰店。有很多普通门店买不到的口味，我爱抹茶冰淇淋🍦！  
- [ ] 叶受和。袜底酥、酒酿饼  
## 平江路  
很窄的一条路，再加上人多，蛮挤的，但很出名…这条路我没买过东西，纯逛逛就行，沿边的店有的还不错。  
## 虎丘  
很大很好玩，天气不热的话去爬爬还挺好玩的，风景也不错。虎丘山和虎丘湿地公园相比，山更有意思一点，但是时间来不及的话，去湿地公园走走也行，记住晚上不太好打车。  
## 西园寺  
去过超多次，学生出示学生证或者学信网🉑免票。寺庙进门可以领香，寺庙超级多小猫咪，茶室里面可以排队抄一页佛经。西园寺的数罗汉很准，可以去试试。西园寺的包子没必要买，不好吃还强制性买一大袋，素面很好吃，一定要加上辣椒或醋！尽量早点去，晚了就要拍长队。  
## 特产一条线（皮市街）  
离拙政园、苏博、北寺塔很近。  
- [ ] 许家酒酿饼。一般般，可吃可不吃，好奇可以尝尝  
- [ ] 近水楼糕团。双酿团很好吃～青团也不错，可惜青团最好吃的一家店已经过季节不卖了。  
- [ ] 杨招娣糕点。在近水楼对面，真的好好吃，有加猪油版，不过我更喜欢纯豆子的，满满的豆香。最少买四分之一哦  
- [ ] 长发西饼。肉月饼很好吃，一定要吃热的  
- [ ] 朱新年点心店。汤圆很好吃，很大一个，一个人吃三个就非常饱了。芝麻花生的香晕了，可以尝试一下肉汤圆，其实还不错哈哈哈。  
- [ ] 万福兴。尽量早点去哟，糕点会全一点，可以买来尝尝，但是不要买太多，趁热吃最好吃！他们家还有面，炒肉面就很好吃。这个季节是炒肉团子上市的季节，但是人很多哦，早点去买能买到。  
## 十全街  
街道布置比较有氛围感，很适合散步🚶‍♂️  
- [ ] 老鲨鱼披萨。披萨好吃  
- [ ] 星仁紫菜包饭。韩餐，味道可以、装修可以、价格可以  
- [ ] 尚记卢食烧饼。还可以哦  
- [ ] 聚福楼。强推炒肉团子，你要是买到了给我带一个……  
- [ ] 余丰堂。麻糍好吃，平江路尽头也有卖的。  
## 白鹭园  
是个公园，偏西式风格，有教堂、水杉林，傍晚看落日很美。  
## 金鸡湖  
挨着苏州中心商场和东方之门（苏州地标大裤衩）。想拍大裤衩就晚上去，可以在下面拍，也可以上苏州中心二楼露台拍。金鸡湖晚上会有点冷，建议带个外套。金鸡湖有月光码头，可以免费坐船；新修的摩天轮也不错🎡；晚上有音乐喷泉；还有一个长桥，拍照也好看。（3或6号线到李公堤西四号口直走到风之园）  
# 其他餐厅推荐  
- [ ] 香雪海。苏州本土特色餐厅  
- [ ] 苏马泰。东南亚餐厅，肉骨茶、吐司好吃  
- [ ] 王烤烤火盆烤肉。品类比较少，但是都是牛肉，适合减肥的人。  
- [ ] 赣湘汇。江西菜，推荐辣子鸡、金钱蛋、小炒黄牛肉，很下饭的一家店，饭点要排队。  
- [ ] 鑫震源。连锁店，生煎还行。  
- [ ] 哥哥的深夜食堂。日式餐厅，店内氛围非常好，味道也很不错。  
- [ ] 本土奶茶：三万昌、本就、树夏（我最喜欢🥰，牛油果的那款酸奶绝了…）、梧桐奶奶、另茶、百分茶
